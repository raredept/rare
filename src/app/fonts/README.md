# Geist local fonts

`geist-sans-latin.woff2` and `geist-mono-latin.woff2` are Latin subsets of the
official Geist 1.7.2 variable fonts. They were generated from the upstream
`Geist-Variable.woff2` and `GeistMono-Variable.woff2` files with fontTools,
retaining weights 100-900, layout features, Portuguese glyphs and common Latin
symbols.

The font files are served by `next/font/local`; production builds do not fetch
fonts from Google or another font service. The SIL Open Font License is kept in
`LICENSE-Geist.txt`.
